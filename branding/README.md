# SocialPulse logo

Designed as a sibling of the DotStark logo: the same orange circle with a white cut-out line, next to a bold, dark, geometric wordmark. In SocialPulse the cut-out is a pulse line that enters through the left edge of the circle, the way DotStark's mark breaks its circle's edge.

| File | Use |
| --- | --- |
| `socialpulse-logo.svg` | Primary logo (mark + wordmark), light backgrounds |
| `socialpulse-logo-dark.svg` | Logo on a black background |
| `socialpulse-mark.svg` | Circle mark only (avatars, sidebar) |
| `socialpulse-app-icon.svg` | App icon: white pulse on an orange rounded square |
| `favicon.svg`, `favicon.ico` | Favicon (circle mark) |
| `png/` | Raster exports |

## Colors

| Token | Hex |
| --- | --- |
| DotStark orange | `#DC6739` |
| Ink (wordmark) | `#0A0A0A` |
| White (cut-out) | `#FFFFFF` |

The orange and ink were sampled from the DotStark logo. If you have the official brand values, swap them into the SVGs.

Wordmark: Poppins SemiBold (SIL Open Font License), converted to outlines so the SVGs don't depend on installed fonts.
