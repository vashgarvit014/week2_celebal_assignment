# SocialPulse brand mark

A pencil nib that writes a single pulse stroke: the idea (nib), the content (the stroke), and publishing (the line rising and accelerating up and to the right). The thin cut between the nib and the stroke is what reads as "pencil", so the shape doesn't need a literal pencil drawing.

| File | Use |
| --- | --- |
| `socialpulse-logo.svg` | Primary horizontal logo, light backgrounds |
| `socialpulse-logo-dark.svg` | Horizontal logo, dark backgrounds |
| `socialpulse-mark.svg` | Symbol only (gradient), sidebar / avatar |
| `socialpulse-mark-mono.svg` | Single-color symbol, uses `currentColor` when inlined |
| `socialpulse-app-icon.svg` | App icon tile |
| `favicon.svg`, `favicon.ico` | Favicon (mark enlarged within the tile for small sizes) |
| `png/` | Raster exports (512/180 app icon, 512 mark, 32/16 favicon, logos at 200px tall) |

## Colors

| Token | Hex |
| --- | --- |
| Indigo (gradient start) | `#4338CA` |
| Violet (gradient end) | `#8B5CF6` |
| Ink ("Social", text) | `#0F172A` |
| Dark-mode mark | `#818CF8` → `#C4B5FD` |

## Wordmark

Plus Jakarta Sans (SIL Open Font License), converted to outlines so the SVGs don't depend on installed fonts. "Social" is set at weight 500 in Ink; "Pulse" is set at weight 650 with an indigo-to-violet gradient.

## Clear space and minimum size

- Keep clear space on every side equal to the nib's length.
- Use the app-icon tile, not the bare mark, below 24px.
